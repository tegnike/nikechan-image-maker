# Automations

このディレクトリには、AIニケちゃん Thumbnail Studioと一緒に運用するCodexスケジューラ定義のGit管理用スナップショットを保存します。

- `ai-t7-10/automation.toml`: 「AIニケちゃん サムネイル素材 10分」の現在の定義
- ライブ設定: `/Users/your-name/.codex/automations/ai-t7-10/automation.toml`

ライブ設定の変更にはCodexアプリのautomation更新機能を使います。変更後はライブ設定とこのスナップショットが一致することを確認してからコミットします。
